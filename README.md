## 🚀 Featured Project — Redixy

> *Most engineers use Redis. This is what it takes to build one.*

Redixy is an in-progress Redis-compatible server written in Java, built from the wire protocol up rather than wrapping an existing client. It speaks the actual RESP protocol over raw TCP — the same layer `redis-cli` talks to — with core command handling (`PING`, `GET`, `SET`) already live and more of the command surface landing as the project grows.

It's the kind of project that forces you past API-level familiarity with a system into how it's actually built: socket handling, protocol framing, and command dispatch, from scratch.
